# 📊 Retail Sales Analysis

## 🛠 Tools Used
- Microsoft Excel

## 📈 Project Overview
This project cleans, analyzes and visualizes retail sales data for UrbanMart outlets.
It covers duplicate removal, missing-value handling, text standardization, formula-driven calculations, conditional formatting and an interactive dashboard built with pivot tables.
The final dashboard shows total sales of $18.59M broken down by outlet type, location tier, fat content, outlet size and establishment year.

## 💡 What I Learned
- How to clean messy Excel data using formulas
- How to standardize inconsistent text entries
- How to use lookup formulas and SUMIF/AVERAGEIF for summaries
- How to apply formula-based conditional formatting to highlight whole rows
- How to summarize KPIs using pivot tables
- How to build an interactive dashboard in Excel
